# Human-voice checklist (anti-AI-tells)

Brand-agnostic. Run every draft through this before calling a post done. This is a
**gate**: if a line trips a banned pattern, rewrite it, don't ship it. The per-site
voice guide governs *what* the post sounds like; this governs *that it doesn't sound
like a machine wrote it*.

## Banned phrases and patterns
- **Filler openers:** "In today's fast-paced world," "In an era of," "As technology
  evolves," "Now more than ever."
- **The not-just-X-but-Y reflex:** "It's not just X, it's Y." "More than just a…"
  One contrast per post at most, and only when it earns its place.
- **Stacked tricolons** used for rhythm rather than meaning (three parallel clauses
  every other sentence). One deliberate triad is fine; a habit of them is a tell.
- **Hype verbs:** unlock, supercharge, harness, revolutionize, empower, elevate,
  delve, navigate (as metaphor), leverage (as verb).
- **Hollow connectors:** "That being said," "At the end of the day," "When it comes to,"
  "It's worth noting that."
- **Fake balance / hedging:** "While there are challenges, the benefits are clear."
  Take a side.
- **Conclusion throat-clearing:** "In conclusion," "Ultimately," "To sum up." End on a
  concrete forward point instead.
- **Em-dash overuse.** Cap at one or two per post. Prefer a period.
- **Generic enthusiasm:** exclamation points, "exciting," "amazing," "powerful."

## Positive rules
- **Make a claim someone could disagree with.** If every sentence is safe, it's slop.
- **Specifics over abstractions.** Real numbers, real constraints, real tradeoffs,
  named tools. "Cut re-briefing from every session to none" beats "improved efficiency."
- **Vary sentence length.** Follow a long sentence with a short one. Let some sentences
  be five words.
- **Show the friction.** Name what was hard or what you got wrong. Honesty reads as
  human; polish reads as generated.
- **Cut the throat-clearing first sentence.** Start at the actual point.
- **Read it aloud.** If you wouldn't say it to a sharp colleague, rewrite it.

## Final pass
Ask: *Could this paragraph appear in any company's blog with the nouns swapped out?*
If yes, it's generic — make it specific to this site, this project, this decision.
